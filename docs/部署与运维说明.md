# 部署与运维说明

> 面向把 `src/` 跑起来的人。所有路径以仓库根目录为起点。

## 一、目录约定

| 路径 | 作用 | 是否入库 |
| --- | --- | --- |
| `src/app/` | FastAPI 路由、RBAC、审计、检索、建议生成 | 是 |
| `src/web/` | 单页前端（检索 / Wiki / 建议 / 审计） | 是 |
| `src/data/graph.json` | 知识图谱（63 节点） | 是 |
| `src/data/runtime/` | 运行时生成：用户、建议、审计、事件 | 否（.gitignore） |
| `src/data/docs/` | 从 `docs/` 复制的业务文档 | 否（构建时生成） |

## 二、端口与进程

| 组件 | 默认端口 | 说明 |
| --- | --- | --- |
| MVP 服务（uvicorn） | 8010 | `run.ps1` 默认；容器内为 8000 |
| 本地模型（Ollama） | 11434 | 可选，未启动时自动回落规则引擎 |

启动：

```powershell
cd src
./run.ps1            # 自动建环境、构建索引、打开 http://127.0.0.1:8010
```

容器：

```bash
docker build -t learning-support-mvp .
docker run -p 8000:8000 learning-support-mvp
```

## 三、配置项（`src/config.json`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `llm.enabled` | `false` | 关闭时走确定性规则，功能完整可演示 |
| `llm.base_url` | `http://127.0.0.1:11434` | 本地 Ollama 地址 |
| `llm.model` | `qwen3:4b` | 换模型只改这一行 |
| `thresholds.advice_confidence_min` | `0.55` | 低于该值转为人工 |
| `rbac.allow / rbac.deny` | 见文件 | deny 优先于 allow |

模型相关的环境变量（不属于本服务，属于 Ollama）：

| 变量 | 作用 |
| --- | --- |
| `OLLAMA_MODELS` | 模型存放目录，建议放大盘 |
| `OLLAMA_IGPU_ENABLE=1` | 启用核显（Vulkan）推理 |

## 四、启动自检

```bash
curl http://127.0.0.1:8010/health
# {"ok": true, "chunks": 274, "graph": {"nodes": 63, "edges": 37}}
```

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `/health` 返回 `ok: false` | 索引未构建 | 跑 `scripts/build_index.py` |
| 建议始终 `llm.used=false` | 模型未启动或未启用 | 看 `GET /llm/status` 的 `reachable` |
| 审计校验失败 | 日志被外部改动 | 检查 `data/runtime/audit.jsonl`，必要时归档重建 |
| 端口占用 | 上一次进程未退出 | 换端口：`./run.ps1 8020` |
