# 算力成本与三年 TCO

> 05 章。API / 云租 / 自购三种买法算三年总账，含电费与盈亏平衡点。

## 一、三种买法

| 方式 | 单价 | 年成本 | 说明 |
| --- | ---: | ---: | --- |
| API（DeepSeek flash） | 8.6 元/月 | **103 元** | 按六场景 6.2M token/月 |
| API（Qwen4-Max） | 73.8 元/月 | **886 元** | 高价模型口径 |
| 云租 CPU（4C16G） | 600 元/月 | **7,200 元** | 跑本机小模型 + 检索 |
| 云租 GPU（24G 显存） | 2,500 元/月 | **30,000 元** | 高并发私有化 |
| 自购整机（4090 24G） | 一次性 24,000 元 | **8,540 元**（折旧 8,000 + 电费 540） | 按 3 年直线折旧 |

## 二、电费不能漏

| 参数 | 取值 |
| --- | ---: |
| 整机功耗 | 450 W |
| 日均运行 | 8 小时 |
| 年运行天数 | 250 天 |
| 年耗电 | 450 × 8 × 250 ÷ 1000 = **900 kWh** |
| 电价 | 0.6 元/kWh |
| **年电费** | **540 元** |

三年 1,620 元——单项不大，但报价时漏掉就是纯亏。

## 三、三年 TCO

| 方案 | 第一年 | 第二年 | 第三年 | 三年合计 |
| --- | ---: | ---: | ---: | ---: |
| API flash | 103 | 103 | 103 | **309** |
| API Qwen-Max | 886 | 886 | 886 | **2,658** |
| 云租 CPU | 7,200 | 7,200 | 7,200 | **21,600** |
| 云租 GPU | 30,000 | 30,000 | 30,000 | **90,000** |
| 自购整机 | 24,000 | 540 | 540 | **25,080** |

（自购首年含购机 24,000，后两年只有电费 540；折旧口径下表已计入年成本。）

## 四、盈亏平衡

| 对比 | 平衡点 | 结论 |
| --- | --- | --- |
| API vs 自购 | 自购三年 25,080 ÷ 36 = 698 元/月；按 0.0615 元/条 → **约 11,350 条/月** | 本项目 1,200 条/月，自购永不回本 |
| API vs 云租 CPU | 7,200 ÷ 12 = 600 元/月 → 约 **9,760 条/月** | 同上 |
| 自购 vs 云租 GPU | 云租 30,000/年 vs 自购 8,540/年 | 用量持续超 1 年即自购更省 |

**结论**：只有「长期高并发私有化」才值得自购 GPU。本项目属于小用量 + 数据不出校，正确解是**本机现有设备跑**（增量成本≈电费），而不是买卡。

## 五、对本项目报价的影响

成本表里服务器按「云租 CPU 600 元/月」计 7,200 元/年，是保守口径：

| 口径 | 年成本 | 说明 |
| --- | ---: | --- |
| 校内虚拟机（实际） | 0 | 试点期复用现有资源 |
| 云租 CPU（报价口径） | 7,200 | 若客户不提供机器 |
| 本机（当前 MVP） | ≈ 电费 100 元 | 一台笔记本，20 tok/s |

报价取中间偏保守的 7,200，理由是「客户不保证提供服务器时必须能交付」。
