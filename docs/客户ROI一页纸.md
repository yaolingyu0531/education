# 客户 ROI 一页纸

> 练 5。四类收益分开算，带回本与敏感性。

## 一、收益侧

### 收益 1：人力节省（主要收益）

| 参数 | 取值 | 来源 |
| --- | ---: | --- |
| 受影响教师 | 20 人 | 600 ÷ 30 |
| 每人每月整理时间 | 10 小时 | 访谈 f12（待验证） |
| 学年工时 | 1,000 小时 | 20 × 10 × 5 个月 × 1 学期 × 2 |
| AI 替代比例（基准） | 40% | 只算搬运与格式化 |
| 校内综合成本 | 60 元/小时 | 含社保等效口径 |
| **年节省** | **48,000 元** | 1,000 × 40% × 60 × 2 |

### 收益 2：产能与时效（不折钱）

反馈周期从学期末一次性变为双周，观察窗口由 0 次增至 10 次/学期。只作价值陈述，不折金额。

### 收益 3：差错与风险减少

| 参数 | 取值 |
| --- | ---: |
| 换岗错发 | 约 10 例/学期（待核） |
| 每例损失 | 240 元（0.5 人天 × 8 小时 × 60） |
| 降低比例 | 80% |
| **年节省** | **3,840 元** |

### 收益 4：收入增量

校内场景不适用，不计入。

## 二、成本侧

| 项 | 金额 |
| --- | ---: |
| 首年实施费 | 63,850 |
| 年服务费 | 22,875 |
| **首年总投入** | **86,725** |
| 续年服务费 | 22,875 |

## 三、回本

| 档位 | 年收益 | 回本周期 |
| --- | ---: | ---: |
| 保守（节省 25%） | 33,840 | 2.56 年 |
| **基准（节省 40%）** | **51,840** | **1.67 年** |
| 乐观（节省 55%） | 69,840 | 1.24 年 |

三年总账（基准）：投入 86,725 + 22,875 × 2 = 132,475；收益 51,840 × 3 = 155,520；**净收益 23,045**。

## 四、敏感性

| 变量 | 影响 |
| --- | --- |
| AI 替代比例 ±5pp | 年收益 ±6,000 |
| 教师工时基线 10h → 6h | 年收益降至 28,800，回本 3.0 年 |
| 模型升级（4B → 32B） | 年成本 +2,400，回本 +0.05 年（不敏感） |
| 换岗错发频次 | 占收益 7%，不敏感 |

> 结论：ROI 的成败几乎全押在「教师工时基线」与「替代比例」两项，这两项正是试点第一周要采集的。
