# 客户 ROI 一页纸

> 练 5。四类收益分开算，带回本曲线与敏感性分析。

## 一、收益侧（只算可验证的）

### 收益 1：人力节省（主要收益）

| 参数 | 取值 | 来源 |
| --- | ---: | --- |
| 受影响教师 | 20 人 | 600 名学生 ÷ 每人 30 人 |
| 每人每月整理时间 | 10 小时 | 访谈 f12（待样本验证） |
| 学期月数 | 5 | 假设 |
| 学年工时 | 1,000 小时 | 20 × 10 × 5 |
| AI 替代比例（基准） | 40% | 只算搬运与格式化，不含判断 |
| 校内综合成本 | 60 元/小时 | 含社保的等效口径 |
| **年节省** | **48,000 元** | 1,000 × 40% × 60 × 2 学期 |

> 注意：节省比例只算被真正替代的环节。教师仍然要做判断与签核，不能把「提效」说成「减人」。

### 收益 2：产能与时效（不折钱）

反馈周期从「学期末一次性」变为「双周」，观察窗口从 0 次变为 10 次/学期。**这项不折算成金额**，只作为方案价值陈述。

### 收益 3：差错与风险减少

| 参数 | 取值 |
| --- | ---: |
| 换岗错发案例 | 约 10 例/学期（待核） |
| 每例损失 | 0.5 人天 × 8 小时 × 60 元 = 240 元 |
| 年损失 | 4,800 元 |
| 降低比例（基准） | 80% |
| **年节省** | **3,840 元** |

### 收益 4：收入增量

校内场景不适用，**不计入**。

## 二、成本侧

| 项 | 金额 | 说明 |
| --- | ---: | --- |
| 首年实施费 | 63,850 | 人力 + 数据 |
| 年服务费 | 21,825 | 模型 + 服务器 + 运维 |
| **首年总投入** | **85,675** | |
| 续年服务费 | 21,825 | 无实施费 |

## 三、回本

| 档位 | 年收益 | 回本周期 |
| --- | ---: | ---: |
| 保守（节省 25%） | 30,000 + 3,840 = 33,840 | **2.5 年** |
| **基准（节省 40%）** | **48,000 + 3,840 = 51,840** | **1.65 年** |
| 乐观（节省 55%） | 66,000 + 3,840 = 69,840 | **1.2 年** |

三年总账（基准）：投入 85,675 + 21,825 × 2 = 129,325；收益 51,840 × 3 = 155,520；**净收益 26,195**。

## 四、敏感性

影响最大的三个变量，按影响从大到小：

1. **AI 替代比例**：每变动 5 个百分点，年收益变动 6,000 元
2. **教师整理工时基线**：10 小时/月是访谈估值，若实际为 6 小时，年收益降至 28,800
3. **换岗错发频次**：仅占总收益 7%，不敏感

> ROI 能用，但**必须先验证前两项**——这也是试点第一周要采集「2 名教师 × 2 周计时日记」的原因。
