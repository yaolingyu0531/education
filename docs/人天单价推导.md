# 人天单价推导

> 两种口径并排：**正式员工口径**用于对照，**实习生＋导师复核的混合口径**是本项目实际采用的。

## 一、正式员工口径（对照）

| 参数 | 取值 |
| --- | ---: |
| 月薪（元） | 22,000 |
| 综合成本系数 | 1.55 |
| 可计费利用率（%） | 80 |
| 成本加成率（%） | 25 |

| 步骤 | 公式 | 结果 |
| --- | --- | ---: |
| 月综合成本 | 22,000 × 1.55 | 34,100 |
| 人天综合成本 | 34,100 ÷ 21.75 ÷ 0.80 | 1,960 |
| 对外人天单价 | 1,960 × 1.25 | **2,450** |

## 二、实习生口径（本项目交付主体）

| 参数 | 取值 | 说明 |
| --- | ---: | --- |
| 月薪（元） | 4,500 | 实习津贴 |
| 综合成本系数 | 1.35 | 无完整福利，仅摊工位与保险 |
| 可计费利用率（%） | 85 | 实习生出勤稳定，可计费比例更高 |
| 成本加成率（%） | 15 | 实习单价不宜高加成 |

| 步骤 | 公式 | 结果 |
| --- | --- | ---: |
| 月综合成本 | 4,500 × 1.35 | 6,075 |
| 人天综合成本 | 6,075 ÷ 21.75 ÷ 0.85 | 329 |
| 实习生对外单价 | 329 × 1.15 | **378** |

## 三、必须叠加的导师复核

实习生不能独立交付——每个交付物都要导师看一遍。按实习生工时的 25% 折算导师投入：

| 组成 | 计算 | 金额 |
| --- | --- | ---: |
| 实习生单价 | 见上 | 378 |
| 导师复核 | 2,450 × 25% | 612 |
| **混合单价** | 378 + 612 | **约 990 元/人天** |

**为什么不能只按 378 报价**：漏掉导师复核会让成本表少算 612 元/人天，42 人天就是 25,704 元的缺口——这正是「最容易漏的一块」在人力上的翻版。

## 四、口径对比

| 口径 | 人天单价 | 42 人天人力成本 |
| --- | ---: | ---: |
| 正式员工 | 2,450 | 102,900 |
| 实习生（漏算复核） | 378 | 15,876 |
| **实习生＋导师复核** | **990** | **41,580** |

**本项目采用 990 元/人天。**
