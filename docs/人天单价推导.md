# 人天单价推导

> 依据人天测算器导出（练 2）。本项目全部报价与成本表按此单价重算。

## 一、参数

| 参数 | 取值 |
| --- | ---: |
| 月薪（元） | 22,000 |
| 综合成本系数 | 1.55 |
| 可计费利用率（%） | 80 |
| 成本加成率（%） | 25 |

## 二、三级推导

| 步骤 | 公式 | 结果 |
| --- | --- | ---: |
| 月综合成本 | 22,000 × 1.55 | **34,100** |
| 人天综合成本 | 34,100 ÷ 21.75 ÷ 0.80 | **1,960** |
| 对外人天单价 | 1,960 × (1 + 25%) | **2,450** |

复核：34,100 ÷ 21.75 = 1,567.8；1,567.8 ÷ 0.8 = 1,959.8 ≈ 1,960；1,960 × 1.25 = 2,450。

## 三、对我们项目的含义

此前成本表按 **1,800 元/人天** 估算，比测算器口径低 **650 元/人天（26.5%）**：

- 42 人天 × 650 = **27,300 元**的差额被低估；
- 若仍按 1,800 报价，等于每投入一人天亏 650 元。

**结论：报价与成本表统一改用 2,450 元/人天，外采项（模型、服务器、数据）不变。**
