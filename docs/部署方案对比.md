# 部署方案对比与推荐配置

> 练 4。API / 自建 / 混合三方案都算一遍，含盈亏平衡点。

## 一、三方案对比

| 维度 | A 纯 API | B 本机 Ollama（当前） | C 云 GPU 自建 |
| --- | --- | --- | --- |
| 月成本 | 3 元 | 0 元（自有设备） | 2,000～3,000 元 |
| 数据边界 | 脱敏后出校 | **不出校** | 不出校（私有云） |
| 单条时延 | 1～2 秒 | 5～10 秒（核显 20 tok/s） | 1～3 秒 |
| 并发 | 按量弹性 | 单并发 | 高 |
| 运维 | 无 | 需一台常开机器 | 需运维 GPU |
| 适用 | 用量小、可脱敏 | **试点期、数据敏感** | 高并发、强合规 |

## 二、盈亏平衡

API 3 元/月 vs 自建 2,500 元/月 → 需要 **833 倍**用量（约 100 万条/月）自建才开始划算。本项目 1,200 条/月，**自建永不回本**。

所以只有两个现实选项：API（可脱敏）或本机（不可出校）。当前选择本机。

## 三、显存实算（qwen3:4b，INT4）

| 项 | 公式 | 结果 |
| --- | --- | --- |
| 权重 | 4.02B × 0.5 GB/B | 2.01 GB（实测 2,375 MiB ≈ 2.32 GB） |
| KV Cache | 36 层 × 8 KV 头 × 128 维 × 2（K+V）× 2 字节 = 144 KB/token；× 4,096 上下文 × 1 并发 | 576 MiB（实测一致） |
| 运行开销 | compute buffer + 10% | 81 MiB + 余量 |
| **合计** | | **约 3,032 MiB（实测 3,032 MiB）** |

公式与实测吻合，说明「显存三件套」可以用于前期选型。

## 四、推荐配置单

| 项 | 推荐 | 理由 |
| --- | --- | --- |
| 显存 | ≥ 4 GB（INT4 4B + 4K 上下文） | 实测 3.0 GB，留 30% 余量 |
| 内存 | ≥ 16 GB | 模型加载与检索索引 |
| CPU | 8 核以上 | BM25 检索与并发请求 |
| 存储 | ≥ 20 GB | 模型 2.5 GB + 索引与日志 |
| 网络 | 内网即可 | 数据不出校 |
| 现有设备 | Intel Arc 核显 16 GB | 实测 20 tok/s，够试点用 |

**结论**：试点阶段不需要买 GPU，现有笔记本即可；若并发超过 3 人同时使用，再考虑云 GPU。
