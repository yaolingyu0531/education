# 部署方案对比与推荐配置

> 练 4。API / 自建 / 混合三方案都算一遍，含盈亏平衡点与**报价采用的口径**。

## 一、三方案对比

| 维度 | A 纯 API | B 本机 Ollama | C 云租 CPU/GPU |
| --- | --- | --- | --- |
| 年成本 | 103～886 元 | ≈ 电费 100 元 | **7,200 元（4C16G）** |
| 数据边界 | 脱敏后出校 | 不出校 | 不出校（私有云） |
| 单条时延 | 1～2 秒 | 5～10 秒（核显 20 tok/s） | 1～3 秒 |
| 并发 | 按量弹性 | 单并发 | 高 |
| 运维 | 无 | 需一台常开机器 | 需运维 |
| 适用 | 用量小、可脱敏 | 试点期、临时演示 | **正式部署** |

## 二、报价采用的口径

**成本表里的服务器块 = 云租 4C16G × 12 个月 = 7,200 元/年**，这是报价基准。

| 场景 | 实际支出 | 说明 |
| --- | ---: | --- |
| 试点期（团队自备机器） | ≈ 0 | 用现有笔记本，只耗电 |
| 正式部署（客户无机器） | 7,200 | 云租 4C16G |
| 客户提供校内虚拟机 | 0 | 成本表可将该项减为 0，报价相应下调 |

报价按 7,200 计的理由：不假设客户一定提供算力，否则交付时可能因缺机器而卡住。

> 早期版本这里写的是「推荐本机 0 元」，与成本表 7,200 不一致，已修正为「报价按云租计，试点期可用本机过渡」。

## 三、盈亏平衡

| 对比 | 平衡点 | 结论 |
| --- | --- | --- |
| API vs 云租 CPU | 7,200 ÷ 12 ÷ 0.0615 ≈ **9,760 条/月** | 本项目 1,200 条，API 更省 |
| API vs 自购 | 25,080 ÷ 36 ÷ 0.0615 ≈ **11,330 条/月** | 自购永不回本 |
| 云租 vs 自购 | 云租 30,000/年 vs 自购 8,540/年 | 需长期高并发才自购 |

所以只有两个现实选项：**API（可脱敏）或云租 CPU（不出校）**。本项目选后者。

## 四、显存实算（qwen3:4b，INT4）

| 项 | 公式 | 结果 |
| --- | --- | --- |
| 权重 | 4.02B × 0.5 GB/B | 2.01 GB（实测 2,375 MiB ≈ 2.32 GB） |
| KV Cache | 36 层 × 8 KV 头 × 128 维 × 2 × 2 字节 = 144 KB/token × 4,096 × 1 | 576 MiB（实测一致） |
| 运行开销 | compute buffer + 余量 | 81 MiB |
| **合计** | | **3,032 MiB（实测 3,032 MiB）** |

## 五、推荐配置单

| 项 | 推荐 | 理由 |
| --- | --- | --- |
| 实例 | 4C16G 云主机 | 与成本表 7,200 元/年对应 |
| 显存 | ≥ 4 GB（若本地跑 4B、INT4） | 实测 3.0 GB，留 30% 余量 |
| 内存 | ≥ 16 GB | 模型加载 + 检索索引 |
| 存储 | ≥ 40 GB | 模型 2.5 GB + 索引 + 日志 + 快照 |
| 网络 | 校内可达即可 | 数据不出校 |
| 备选 | 现有 Intel Arc 核显笔记本 | 试点期零成本过渡，20 tok/s |
