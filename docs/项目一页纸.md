# 项目一页纸

> 开课前填，五项，五分钟。右侧一列说明「为什么先定它」。

| 要填的五项 | 本项目 | 为什么先定它 |
| --- | --- | --- |
| 客户是谁 | 教育行业 · 高职院校（知行职业学院）；600 名实习学生/学期；牵头部门：产教协同办公室（产教融合负责人 顾明岚） | 决定报价模式与谈判对象 |
| 多少人用 | 约 27 人：指导教师 20（每人带 30 人）、教务管理员 1、教学质量负责人 1、产教融合负责人 1、企业实习导师 5～8（试点 5 家企业） | 决定并发与服务口径 |
| 每天多少量 | 学期内月均约 1,200 条反馈（600 人 × 每月约 2 轮双周反馈），约 60 条/工作日；试点期机电 5 家企业约 200～240 条/月 | Token 与算力测算的起点 |
| 数据在哪 | 企业评分与评语散在微信 / Excel / 邮件；学籍与实习批次在校园内网系统；课程平台另一套 ID；历史反馈缺岗位任务字段 | 决定数据与对接工作量 |
| 能不能上云 | 脱敏后可调云端 API；含学生个人信息的个体评价须留校内或私有化部署 | 一票否决项：决定 API 还是私有化 |

## 备注

- 用量为推算：600 名学生、每位教师带 30 人、双周节拍，尚未按样本核实。
- 三处待验证假设：完整率 54%→85%、建议 30 条中至少 24 条可对应、换岗错发。
- 边界：成绩写回不在范围，模型不决定成绩，变更培养方案须教务委员会审批。
