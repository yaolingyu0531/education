# 项目一页纸

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 实习反馈受限整理与教学改进辅助（学习支持与辅导协作） |
| 客户是谁 | 教育行业 · 高职院校（知行职业学院）；在校实习学生 600 人/学期；牵头部门：产教协同办公室（产教融合负责人 顾明岚） |
| 多少人用 | 约 27 人：指导教师 20（每人带 30 人）、教务管理员 1、教学质量负责人 1、产教融合负责人 1、企业实习导师 5～8（试点 5 家企业） |
| 每天多少量 | 学期内月均约 1200 条反馈（600 人 × 每月约 2 轮双周反馈）；试点期机电专业 5 家企业约 200～240 条/月 |
| 数据在哪 | 企业评分与评语散在微信/Excel/邮件；学籍与实习批次在校园内网系统；课程平台另一套 ID；历史反馈缺岗位任务字段 |
| 能不能上云 | 脱敏后可调云端 API；含学生个人信息的个体评价须留校内或私有化部署 |
| 边界 | 成绩写回不在范围；模型不决定成绩；变更培养方案须教务委员会审批 |
| 风险（待验证） | 完整率 54%→85% 的分母未固定；换岗后反馈发错人；建议落不到具体课程 |

> 说明：「多少人用」与「每天多少量」为按 600 名学生、每位教师带 30 人、双周节拍推算，尚未按样本核实。
