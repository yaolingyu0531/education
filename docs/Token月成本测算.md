# Token 月成本测算

> 练 3。按 `docs/使用场景与调用量.md` 的六个场景测算，输入输出分开，三档并列。

## 一、单次调用的 Token 构成（主场景 S1）

| 组成 | Token | 说明 |
| --- | ---: | --- |
| 系统提示词 | 400 | 角色、边界、红线、JSON schema |
| 观察记录 | 250 | 3～5 条，企业导师原始描述 |
| 检索上下文 | 2,240 | 8 段 × 280，覆盖任务 / 实例 / 课程口径 / 验收 |
| 输出格式约束 | 110 | 字段与校验规则 |
| **输入小计** | **3,000** | |
| 输出 | 150 | JSON 建议 2 条 |
| **合计** | **3,150** | |

## 二、三档用量（六场景合计）

| 档位 | 系数 | 输入 | 输出 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 保守 | 0.7 | 3.93 M | 0.41 M | 4.34 M |
| **基准** | **1.0** | **5.61 M** | **0.59 M** | **6.20 M** |
| 高峰 | 1.6 | 8.98 M | 0.94 M | 9.92 M |

高峰取 1.6 倍：学期末集中填报，S1 与 S4 同时上升。

## 三、成本：两种价格口径

| 价格口径 | 输入 / 输出（元/M） | 基准月成本 | 高峰月成本 |
| --- | ---: | ---: | ---: |
| DeepSeek flash（离峰） | 1.08 / 4.32 | **8.60 元** | 13.8 元 |
| Qwen4-Max（按量） | 10 / 30 | **73.7 元** | 118 元 |

计算过程（基准，flash）：5.61 × 1.08 = 6.06；0.59 × 4.32 = 2.55；合计 8.61 元。

## 四、预算口径：100 元/月

预算不按最低价定，按「高价模型 + 峰值 + 余量」定：

| 组成 | 金额 |
| --- | ---: |
| Qwen4-Max 基准月成本 | 73.7 |
| 峰值系数（1.6）与重试余量 | +35% |
| **预算** | **约 100 元/月 = 1,200 元/年** |

理由：模型选型可能因效果不达标而升级（4B → 32B 或云端大模型），按 flash 价定预算会在切换时立刻超支。

## 五、五个降本杠杆

| 杠杆 | 预估节省 |
| --- | ---: |
| 检索段数 8 → 5（先粗排） | 输入 −30% |
| 结果缓存（同一学生同周期复用） | 调用 −15% |
| 批量接口（Batch 半价） | 输入 −50% |
| 本地小模型跑 S4 自检 | S4 归零 |
| 提示词压缩（schema 精简） | 输入 −8% |

## 六、与上一版的差异

| 版本 | 场景数 | 月 token | 模型费/年 |
| --- | ---: | ---: | ---: |
| v1 | 1（每条一次） | 2.26 M | 360 |
| **v2** | **6** | **6.20 M** | **1,200** |

调用量涨 2.7 倍，但按高价模型留余量后预算仍是千元级——**Token 依旧不是主要成本，人力和数据才是**。
