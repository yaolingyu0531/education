# Token 月成本测算

> 练 3。输入输出分开算，保守 / 基准 / 高峰三档。

## 一、单条反馈的 Token 构成

| 组成 | 估算 Token | 说明 |
| --- | ---: | --- |
| 系统提示词 | 350 | 角色、边界、输出格式约束 |
| 观察记录（2～3 条） | 180 | 企业导师写的具体行为 |
| 检索上下文（4 段） | 1,120 | BM25 命中段落，每段约 280 token |
| 输出格式约束 | 80 | JSON schema 说明 |
| **输入小计** | **1,730** | |
| 输出（JSON 建议 2 条） | 150 | 每条建议约 75 token |
| **合计** | **1,880** | |

## 二、三档用量

| 档位 | 月反馈量 | 输入 Token | 输出 Token |
| --- | ---: | ---: | ---: |
| 保守（70%） | 840 | 1.45 M | 0.126 M |
| **基准** | **1,200** | **2.08 M** | **0.18 M** |
| 高峰（150%） | 1,800 | 3.11 M | 0.27 M |

用量基线来自 `docs/项目一页纸.md`：600 名学生 × 每月 2 轮双周反馈。

## 三、成本（DeepSeek flash 离峰价：输入 1.08 元/M、输出 4.32 元/M）

| 档位 | 输入费 | 输出费 | 月合计 | 年合计 |
| --- | ---: | ---: | ---: | ---: |
| 保守 | 1.57 | 0.54 | 2.11 | 25.3 |
| **基准** | **2.25** | **0.78** | **3.03** | **36.4** |
| 高峰 | 3.36 | 1.17 | 4.53 | 54.4 |

按高峰档再打 6 倍安全系数（重试、上下文膨胀、高峰时段 ×2）≈ **30 元/月，360 元/年**。

## 四、结论：模型费不是成本项

| 方案 | 月成本 |
| --- | ---: |
| DeepSeek flash API | 3 元 |
| 本机 Ollama（当前 MVP） | 0 元（只耗电） |
| 云 GPU 自租（4B 常驻） | 2,000～3,000 元 |

此前成本表按「500 元/月 × 12 = 6,000」估模型费，**高估约 20 倍**。真正的成本在人力与数据清洗，不在 Token。
