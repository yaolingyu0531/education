# 正式报价单

> 练 6。前五件拼装成单，首年与续年分开，付款节点、SLA、超范围另计写清。

## 一、项目概述

为知行职业学院产教协同办公室建设「实习反馈受限整理与教学改进辅助系统」，覆盖机电专业 5 家企业的实习反馈整理，输出可追溯的课程改进建议。

## 二、交付范围

| 交付物 | 说明 |
| --- | --- |
| 反馈字段模板 | 岗位任务 + 行为实例 + 改进建议三字段 |
| 整理与建议服务 | FastAPI 服务 + 检索 + 建议生成（人工确认后生效） |
| 审计与权限 | 分层角色、本人签核禁止、哈希链审计 |
| 部署与培训 | 校内私有化部署，2 场培训 |
| 验收材料 | 30 条回放报告、24/30 通过记录 |

**不含**：成绩写回、培养方案变更、企业外部系统改造。

## 三、报价

| 项 | 金额（元） | 说明 |
| --- | ---: | --- |
| 一次性实施费 | 63,850 | 含人力 41,580 与数据 9,500，加成 25% |
| 首年服务费 | 21,825 | 模型 360 + 服务器 7,200 + 运维 9,900，加成 25% |
| **首年合计** | **85,675** | |
| 续年服务费 | 21,825 | 不含实施费 |
| 超量单价 | 8 元/条 | 基础含 1,500 条/月 |

## 四、付款节点

| 节点 | 比例 | 金额 |
| --- | ---: | ---: |

## 五、SLA

| 项 | 承诺 |
| --- | --- |
| 服务可用性 | 工作日 99% |
| 故障响应 | 4 小时内响应，次工作日修复 |
| 数据安全 | 不出校；日志不含口令与非必要个人信息 |
| 留痕 | 全程审计链，可重建当次处理 |

## 六、超范围

以下按 990 元/人天另计：新增专业或企业、新增对接系统、字段口径大改、历史数据全量清洗。

## 七、谈判底线

| 项 | 内容 |
| --- | --- |
| 最低价 | 78,800（成本 × 1.15） |
| 可让 | 运维人天由 10 降为 6（省 3,960 元）；培训场次减 1 场 |
| 不可让 | 数据清洗（9,500）、审计留痕、24/30 验收口径 |
| 常见压价话术 | 「先免费试点」→ 回应：试点可按 68,300 的缩减包做，但验收口径不变 |

## 八、有效期

报价有效期 30 天；模型与云服务价格随行就市，续年费按当年价调整不超过 10%。
