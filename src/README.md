# src · 代码目录

当前阶段以业务调研与需求定义为主，代码尚未落地，本目录为占位。

后续按 `docs/` 中已确认的需求与边界实现，建议拆分：

| 子目录 | 职责 | 对应需求 |
| --- | --- | --- |
| `src/metrics/` | 反馈完整率、24/30 建议可执行率的可复算口径 | REQ-6 |
| `src/mapping/` | 学籍 / 实习 / 课程平台 ID 映射与四项校验 | REQ-4 |
| `src/extract/` | 岗位任务模板字段抽取与人工确认队列 | REQ-1、REQ-5 |
| `src/audit/` | 审核日志与原文追溯 | REQ-5 |

硬边界（实现时不得越过）：

- 只读批量导出，**不做成绩写回**；
- AI 只整理观察事实与建议，**最终评价由导师确认**；
- 每条辅助结果必须能点回原记录，未确认不覆盖原记录；
- 出现换岗、无行为实例、口径不一致、依据缺失或系统不可用时，停止自动建议并转人工。
